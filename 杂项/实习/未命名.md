## **C/C++类**：

这里常考的知识点：1. 求结构体的大小，sizeof(结构体)；

例题：

struct Student  
{  
int i;  
int j;  
char c;  
} ;  
  
int main()  
{  
printf("%d\n",sizeof(Student));  
return 0;  
}
