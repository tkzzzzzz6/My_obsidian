# macOS 常用快捷键总览

## 全局与系统操作
* `「Command + Space」` 打开 Spotlight 搜索
* `「Command + Tab」` 在打开的应用程序之间切换
* `「Command + Shift + Tab」` 反向切换应用程序
* `「Control + 左/右」` 左右切换空间
* `「Control + 上」` 显示调度中心
* `「Control + 下」` 显示当前应用程序窗口
* `「Command + Option + D」` 显示/隐藏程序坞
* `「Command + Option + Esc」` 强制退出应用
* `「Command + Q」` 退出程序
* `「Command + Option + Shift + Esc」` 直接强制退出当前软件

## 窗口管理
* `「Command + W」` 关闭当前窗口（未退出进程）
* `「Command + Option + W」` 关闭所有窗口（未退出进程）
* `「Command + M」` 最小化当前窗口
* `「Command + H」` 隐藏当前软件
* `「Command + Option + H」` 隐藏除当前软件外的所有软件
* `「Command + `」` 当前软件多窗口切换（仅苹果系统软件）
* `「Command + Ctrl + F」` 进入/退出窗口最大化
* `「双击窗口额头」` 访达窗口上下扩大和恢复原大小

## 编辑/复制/粘贴/撤销
* `「Command + X」` 剪切所选项并拷贝到剪贴板（不适用于访达文件）
* `「Command + C」` 拷贝所选项（适用于访达文件）
* `「Command + V」` 粘贴剪贴板内容（适用于访达文件）
* `「Command + Option + C」` 拷贝样式
* `「Command + Option + V」` 粘贴样式（适用于访达文件移动）
* `「Command + A」` 全选各项（适用于访达文件）
* `「Command + Z」` 撤销前一个命令
* `「Command + Shift + Z」` 重做（反向执行撤销命令）
* `「Ctrl + D」` 向后删除（等同于 fn + Delete）
* `「Ctrl + A」` 跳至行首
* `「Ctrl + E」` 跳至行尾
* `「Ctrl + K」` 从当前位置删除至行尾
* `「Ctrl + N」` 跳到下一行
* `「fn + ↑/↓」` page up / page down

## 访达（Finder）相关
* `「Command + N」` 打开新的访达窗口
* `「Command + T」` 打开新的访达标签页
* `「Command + Shift + N」` 新建文件夹
* `「Command + Shift + G」` 打开前往文件夹窗口/搜索路径框
* `「Command + Shift + .」` 显示/隐藏隐藏文件
* `「Command + Up」` 返回上一层文件夹
* `「Command + Down」` 打开当前所选文件夹或文件
* `「Command + Delete」` 移动所选项到废纸篓
* `「Command + Shift + Delete」` 清倒废纸篓
* `「Command + Option + V」` 剪切粘贴文件（粘贴复制好的文件并删除原文件）
* `「Command + Option + C」` 复制目录全路径（如：/Users/mayl/Downloads/96-AfloatX-1.4.1）
* `「Command + I」` 显示目录或文件全路径/信息

## 截图相关
* `「Command + Shift + 3」` 截取当前全屏并保存到桌面
* `「Command + Ctrl + Shift + 3」` 截取全屏并保存到剪切板
* `「Command + Shift + 4」` 拖拽鼠标选择截图区域并保存到桌面
* `「Command + Ctrl + Shift + 4」` 区域截图并保存到剪切板

## 浏览器常用
* `「Command + T」` 打开新标签页
* `「Command + N」` 打开新窗口
* `「Command + W」` 关闭当前标签页
* `「Command + L」` 定位到地址栏
* `「Command + 鼠标点按链接」` 新标签页打开链接
* `「Command + 鼠标点按书签」` 新标签页打开书签

## 其他常用
* `「Ctrl + N」` 桌面打开访达新窗口
* `「Command + Option + D」` 显示/隐藏程序坞
* `「Command + Option + Esc」` 强制退出应用
* `「Command + Option + Shift + Esc」` 直接强制退出当前软件

### 词典功能
* macOS 自带词典（Dictionary），可在任何应用中通过重按触摸板显示单词释义。
* 若喜欢三指轻拍触摸板，可在 [System Settings] > [Trackpad]，在 [Point & Click] 标签页中选择 [Look up & data detectors] > [Tap with Three Fingers]。
* 也可直接打开 Dictionary 应用查找单词，并可添加英汉汉英词典。
8 文本编辑操作
光标移动
Ctrl ⌃ + F, 光标前进一个字符（F = Forward）
Ctrl ⌃ + B, 光标后退一个字符（B = Backward）
Ctrl ⌃ + P, 光标上移一行（P = Previous）
Ctrl ⌃ + N, 光标下移一行（N = Next）
Ctrl ⌃ + A, 光标移动到当前行或段落开头（A = Ahead）
Ctrl ⌃ + E, 光标移动到当前行或段落结尾（E = End）
Command ⌘ + Up ⬆︎ / Down ⬇︎, 光标移动到全部文本开头 / 结尾
Command ⌘ + Left ⬅︎ / Right ➡︎, 光标移动到当前行的行首 / 行尾
Option ⌥ + Left ⬅︎ / Right ➡︎, 光标移动到当前单词的开头 / 结尾
文本选中
在光标移动中带有方向键 Up ⬆︎ / Down ⬇︎ / Left ⬅︎ / Right ➡︎ 相关快捷键的基础上，加入 Shift ⇧，则可以扩展为选中文本效果的快捷键。

Command ⌘ + Shift ⇧ + Up ⬆︎ / Down ⬇︎, 选中光标到全部文本开头 / 结尾的文本
Command ⌘ + Shift ⇧ + Left ⬅︎ / Right ➡︎, 选中光标到当前行的行首 / 行尾的文本
Option ⌥ + Shift ⇧ + Left ⬅︎ / Right ➡︎, 选中光标到当前单词的开头 / 结尾的文本
文本删除
Ctrl ⌃ + H 或 Delete, 删除光标前面的一个字符
Ctrl ⌃ + D 或 Fn + Delete, 删除光标后面的一个字符
Option ⌥ + Delete, 删除光标前面的一个单词
Command ⌘ + Delete, 删除光标之前的整行内容
Ctrl ⌃ + K, 删除光标之后的整行内容
