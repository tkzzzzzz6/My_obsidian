您好呀！以下是我近期在 AI Agent 领域的项目与研究成果:

项目 1： 借助 AI 编程工具构建了一个多级协作式溺水检测与智能预警 Agent 系统 downing_detect。系统采用三级长链推理架构：第一级由 YOLOv11 检测 Agent 实时提取视频流中的人体目标框、置信度与空间位置；第二级将结构化检测结果输入 LLM 推理 Agent 进行二次语义判断，区分正常游泳与溺水风险行为（如长时间静止、异常沉浮），实现从像素级识别到语义级理解的跃迁；第三级由报告生成 Agent 自动整合地理位置、时间戳、视频关键帧、风险等级等多模态信息，生成结构化预警邮件并推送至管理端。检测 Agent → 推理 Agent → 报告 Agent 形成闭环协作，无需人工介入即可完成从风险识别到告警通知的全流程，解决了公共水域监控中人工值守效率低、漏检率高、事后追溯难的痛点。

项目 2： 我同样使用 AI 编程工具驱动开发了多模态 AI 聊天平台 maya-llm-ui。开发过程中，AI Agent 辅助完成了 Next.js + TypeScript 前端架构搭建、多模型后端接口（OpenAI / QWen / Ollama）的统一封装、Supabase 实时数据库的集成，以及语音聊天（YAYA 语音服务）和视频对话（通义千问 QWen 视觉模型）功能的模块化组件设计。该项目解决了主流 Chatbot UI 缺乏原生多模态交互的痛点，目前已部署至 Vercel 并提供在线演示。

科学研究： 我也将 LLM Agent 深度融入学术研究全流程，在最近的研究中使用 GPT 系列模型辅助编写空间多组学数据预处理的实验脚本、设计超参数调优逻辑，以及润色论文初稿与优化结构表达，显著提升了科研迭代效率与产出质量。
