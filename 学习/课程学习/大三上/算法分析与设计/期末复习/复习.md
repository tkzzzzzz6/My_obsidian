1. 选择排序
> 输入:包含n个数字的数组A[a1,...,an]
> 输出:升序排列的数组A'[a1',...,an'],(满足a1'< a2' < ... < an')
```cpp
for i ← 1 to n-1 do
    for j ← i + 1 to n do
        # 如果A[i] > A[j]
        if A[i] > A[j] then
            swap(A[i],A[j])
        end
    end
end
```
- python
```py
for i in range(1,n):
    for j in range(i+1,n+1):
        if A[i] > A[j]:
            swap(A[i],A[j])
```
