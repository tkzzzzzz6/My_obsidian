### 2.11 多项式的根计算

#### 问题描述：

给定多项式 $P(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_{n-1} x^{n-1} + x^n$，要求设计一个分治算法，通过算法 $A$ 和 $B$ 来计算多项式的根。

#### 求解思路：

1. **问题理解：**  
    我们的目标是计算多项式 $P(x)$ 的根。给定的多项式具有 $n$ 个系数，并且我们知道多项式的最高次项系数是 1（即 $x^n$）。
    
2. **算法选择：**
    
    - 算法 $A$：可以在 $O(k)$ 时间内计算一个次多项式与一个 1 次多项式的积。这个算法是处理低次项（次多项式和线性多项式）的计算。
        
    - 算法 $B$：可以在 $O(\log i)$ 时间内计算两个次多项式的积。这个算法主要用来处理高次项多项式的乘法运算。
        
3. **分治策略：**
    
    - 我们可以将多项式分解成较小的子问题。通过递归地拆分多项式，逐步将多项式转化为较低次的多项式，并利用算法 $A$ 和 $B$ 来计算各个子问题。
        
    - 在每次分解过程中，低次项的积由算法 $A$ 计算，高次项的积则由算法 $B$ 来计算。
        
    - 这种分治方法可以有效减少多项式的计算量，从而提高求解效率。
        
4. **时间复杂度：**
    
    - 由于每次分治将多项式的阶数减半，递归的深度为 $O(\log n)$。
        
    - 每个子问题的计算量是 $O(n)$（因为最终的计算是与多项式的度数成正比的），因此总时间复杂度为 $O(n \log n)$。
        

#### 答案：

该问题通过分治策略使用算法 $A$ 和 $B$，能有效地计算多项式的根。最终时间复杂度为 $O(n \log n)$。

    - **7 个一组：** 如果将元素分成 7 组，递归的深度将更小，理论上可以更快地缩小问题规模。递归深度为 $O(\log_7 n)$，但由于常数因子的不同，7 个一组的性能可能更优，虽然理论时间复杂度仍为 $O(n)$，但常数项会更小，效率更高。
        
3. **时间复杂度对比：**
    
    - 选择不同的分组数会影响算法的常数因子，但最终的时间复杂度在最坏情况下仍然是线性的 $O(n)$。
        

#### 答案：

### 2.17 查找两个数之和

#### 问题描述：

给定 $n$ 个不等的整数构成的集合 $L$ 和整数 $s$，设计一个算法判断在 $L$ 中是否存在两个整数 $x$ 和 $y$（$x < y$），满足 $x + y = s$，并分析算法的时间复杂度。

#### 求解思路：

1. **问题分析：**
    
    - 这道题是经典的 “查找两数之和” 问题。目标是从集合 $L$ 中找到两数之和等于 $s$，并且 $x < y$。
        
2. **暴力法：**
    
    - 通过两层循环遍历集合 $L$ 中的所有数对，检查是否有 $x$ 和 $y$ 满足 $x + y = s$，时间复杂度为 $O(n^2)$。但这种方法效率较低。
        
3. **排序 + 双指针法：**
    
    - **排序：** 首先将集合 $L$ 排序，时间复杂度为 $O(n \log n)$。
        
    - **双指针：** 排序之后，可以使用双指针法。初始化两个指针，一个指向数组的开头，另一个指向数组的末尾：
        
        - 如果指针指向的两数之和等于 $s$，返回 True。
            
        - 如果和小于 $s$，左指针右移。
            
        - 如果和大于 $s$，右指针左移。
            
    - 通过双指针法，我们可以在一次扫描中找到满足条件的数对，时间复杂度为 $O(n)$。
        
4. **时间复杂度：**
    
    - 排序的时间复杂度为 $O(n \log n)$，双指针扫描的时间复杂度为 $O(n)$，因此总的时间复杂度为 $O(n \log n)$。
        
#### 答案：

该问题的时间复杂度为 $O(n \log n)$，通过排序和双指针方法可以高效地解决。

### 2.22 对称差计算

#### 问题描述：

设 $A = {a_1, a_2, \dots, a_m}$，$B = {b_1, b_2, \dots, b_n}$ 是整数集合，其中 $m = O(\log n)$。设计一个算法计算集合 $C = (A - B) \cup (B - A)$，并分析算法在最坏情况下的时间复杂度。

#### 求解思路：

1. **问题分析：**
    
    - 对称差是集合 $A$ 和 $B$ 的差集，即 $A$ 中有而 $B$ 中没有的元素，以及 $B$ 中有而 $A$ 中没有的元素。
        
2. **算法设计：**
    
    - 计算 $A - B$：遍历集合 $A$，删除其中同时存在于 $B$ 中的元素。
        
    - 计算 $B - A$：遍历集合 $B$，删除其中同时存在于 $A$ 中的元素。
        
    - 最后，合并 $A - B$ 和 $B - A$，得到对称差 $C$。
        
3. **时间复杂度：**
    
    - 计算 $A - B$ 和 $B - A$ 都需要遍历集合 $A$ 和 $B$，时间复杂度为 $O(m + n)$，其中 $m = O(\log n)$。
        
    - 合并两个集合的时间复杂度为 $O(m + n)$。
        
    - 因此，总的时间复杂度为 $O(m + n)$，即 $O(\log n + n)$。
        
#### 答案：

该问题的时间复杂度为 $O(\log n + n)$，通过集合差集和并集的操作可以高效地计算对称差。
