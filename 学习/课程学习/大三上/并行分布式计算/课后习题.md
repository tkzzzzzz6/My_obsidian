3. Global File System与Google FileSystem的区别？
Global File System (GFS) 是一种开源的、产品化的集群文件系统，又 名“红帽全球文件系统”，Red Hat公司按照服务器数量收取服务费（约2200美元每台服务器每年）。但其原理性文档少之又少，技术细节未公开。
• Google File System (GFS) 是 由Google设计用于其内部使用的分布式文件系统。部分技术细节有公开发表论文。
4. HDFS与GFS的区别？
HDFS, Hadoop Distributed File System 。Hadoop 是 一 个 开 源 的分布式计算框架 ， 其中包含了MapReduce分布式计算模型和HDFS分布式文件系统。GFS是由Google设计用于其内部使用的分布式文件系统。
• HDFS与GFS的设计目标类似，但在文件块的大小、数据复制策略等方面有所不同。例如，GFS的块大小为64MB，HDFS 为 128MB 。 GFS 的 元 数 据 由 主 节 点 维 护 ， 而HDFS由主节点和从节点共同维护
