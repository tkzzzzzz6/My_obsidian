# 19. Bigtable中有哪 3 种压缩方式?是怎样进行的?
1. Bigtable中有次压缩,合并压缩,主压缩三种压缩方式
2. Bigtable 中每次旧的内存表停止使用时都会执行一次次压缩操作,产生一个 SSTable
3. Bigtable 会定期执行一次合并压缩操作,将一些已有的 SSTable 和现有的内存表一并进行一次压缩
4. Bigtable 中的主压缩其实是合并压缩的一种,将所有 SSTable 一次性压缩成一个大的 SSTable 文件,该操作也是定期执行一次,一次主压缩之后,所有被压缩数据会被彻底删除,即回收了空间又能保证敏感数据的安全性

# 21. 为了减少开销,提高客户访问效率,Bigtable 使用了哪两种技术?其含义分别是什么?
1. Bigtable 采用了缓存和预存取技术
2. 缓存是指子表的地址信息被缓存在客户端,客户寻址时,直接根据缓存信息进行查找
3. 预存取是指在每次访问元数据表的时候,不仅仅读取所需的子表元数据,而是读取多个子表的元数据,这样下次需要的时候,就不用再次访问元数据表了
# 22. Bigtable的局部性群组是指什么?
1. Bigtable中允许用户将原本并不存储在一起的数据以列族为单位,根据需要组织在一个单独的 SSTable 中,以构成一个局部性群组
# 23. MegaStore 中有哪几种类型的副本?分别是什么副本?其功能是什么?
1. MegaStore 中有三种类型的副本,分别是完整副本,见证者副本和只读副本
2. 完整副本用于存储完整的数据和日志
3. 见证者副本只存储日志,而不存储数据,只在 Paxos 算法执行过程中,无法产生决议时参与投票
4. 只读副本只存储数据,不参与投票,且该副本知识读取到过去某个时间点的数据,如果读操作能够容忍这些过期的数据,则只读副本会在不加剧'写延迟的'的情况下,将数据在较大的地理空间上传输
# 24. MegaStore中的快速读和快速写是什么?
1. 快速读:当协调者查询到本地副本的数据是最新的数据的时候,可以与其他副本通信,直接读取本地的数据,读效率最高
2. 快速写:如果一次写成功,那么下一次写的时候就可以跳过准备过程,直接进入接受阶段,因为一次写成功,意味着已经知道了数据和日志的最新位置,因此,不需要再向协调这查询了,此时写效率最高
# 25. Dapper是怎样汇总监控信息的?
1. Dapper 先将区间的数据写入本地的日志文件中
2. 再通过 Dapper 守护进程收集一台产品主机的本地日志文件
3. 之后,通过 Dapper 收集器收集所有产品主机的本地日志文件
4. 最后,将汇集后的数据写入到 Bigtable 存储库中
# 26. Dapper的二次抽样技术的具体方法是什么?好处是什么?
1. 在数据写入 Bigtable 之前,Dapper 将监控 id 散列成一个标量 Z ,如果某个区间的 Z 小于事先定义好的汇总抽样系数,则保留这个区间,并将它写入 Bigtable,否则丢弃
2. 好处是,只需要改动 Z 值就可以改变整个系统的写入数据量,解决了低开销即广泛可部署性的问题
# 27. Dapper监控信息的汇总需要哪几个步骤?
1. 将区间的数据写入到本地的日志文件中
2. 利用 Dapper 守护进程和 Dapper 收集器将所有机器上的本地日志文件汇集到一起
3. 将汇集后的数据写入到 Bigtable 存储库中

# 32. PowerDrill 和 Dremel 的设计理念有哪些不同?

2. Dremel 未进行数据分区,分析时要扫描所有的列,PowerDrill 使用了组合范围分区,分析时可以跳过很多不需要的分区

# 38. OceanBase中的 ChunkServer 和 UpdateServer 都是用来存储数据的,它们的区别是什么?
1. ChunkServer用于存储基线数据,UpdateServer 用于存储增量更新数据
# 39. OceanBase 中的增量更新数据和基线数据的区别是什么?
1. 增量更新数据是指,在数据库初始数据的基础上,新增加,修改或删除的数据部分,即动态数据(与全量数据相对应),体现了数据库从一个状态到另一个状态的变化,通常较小
2. 基准数据,即主体数据是指在特定时间点或特定条件下被认为是准确,完整的数据版本,用于比较,评估后续数据的变化,性能测试或者系统配置等诸多用途
# 40. OceanBase 采用基线数据和增量更新数据分别存储的优点是什么?
1. ChunkServer 中存储基线数据的方式使得主体数据在一段时间内保持相对稳定
2. UpdateServer 中存储增量更新数据的方式使得动态数据可以存储在内存中,提高了系统写事务的性能
3. 冻结后的内存表可以转化成 SSTable 格式保存到磁盘上,转储以后,内存空间占用即可释放
