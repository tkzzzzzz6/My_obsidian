# 绪论

1. 计算机图形学:研究通过计算机将场景对象转换为图形并进行显示的一门学科

表示:将场景对象转换为图形(造型/建模)
显示:将转换后的图形显示出来(渲染/绘制)

2. 造型:建立物体的三维计算机图形学表示,即用于表示物体的技术,方法或数据结构

3. 渲染:对造型表示后的物体进行可视化,即根据三维物体模型生成二维图像

4. 图形:一种由不同属性(颜色,粗细,图案)的点,线,面等几何元素组成的图画,用来表示主客观世界中各种物体的几何信息,本质上是一种语言

5. 图像:对自然界事物的客观反映,本质上是记录在介质上的客观对象的映像

6. 计算机图形学的发展过程:线框图形学,光栅图形学,真实感图形学,实时图形学
