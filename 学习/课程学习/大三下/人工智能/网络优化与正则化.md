1. 优化算法
2. 参数初始化
3. 修改网络结构->优化地形
4. 超参数的优化
5. batch size的选择


学习率衰减

带热启动的余弦衰减,跳出局部最优解

梯度方向优化

- 动量法
  锯齿状前进
  可以采用累积动量方法

- 梯度截断:解决梯度爆炸的问题
    - 按值截断
    - 按模截断

参数初始化
- 落在激活函数梯度和合理区间中
- 初始化不能设置为 0,因为我们需要打破对称性,比如滤波器的权重不能相同,否则每个滤波器学到的特征都一样
- 初始化方法
    - 预训练初始化
    - 随机初始化
    - 固定值初始化
  
  xavier 初始化,he 初始化,正态分布初始化,均匀分布初始化

输出预处理
- 归一化
  地形从类似椭球形变成类似球形,更容易优化
  - BN:batch normalization
  - LN:layer normalization
  - IN:instance normalization
  - LRN:local response normalization
- 白化
- 标准化
- PCA

网络正则化:regularization,损害优化的方法都属于正则化
- 避免过度依赖,经可能均衡
- 增加优化约束
    - L1/L2正则化:加上参数的范数作为惩罚项,使得参数更小,更稀疏
    - 数据增强
        - cut-bur: LR 和 HR 图像互相局部填充,增强模型的鲁棒性
- 干扰优化过程
    - 早停
    - dropout:丢弃函数,丢弃神经元
