## 一、支持向量机（SVM, Support Vector Machine）

### 1.1 核心思想
支持向量机的目标是找到一个**最优的超平面**，将不同类别的数据分开。与感知机不同，SVM 不仅要求“能分开”，还要求**间隔最大**（Max Margin），从而提升模型的泛化能力。

> 通俗理解：在两类数据之间找一条“最宽的安全通道”，让分界线离两边最近的样本都尽可能远。

### 1.2 安全边界（Margin）
- **间隔（Margin）**：两条与决策边界平行的虚线之间的距离。这两条虚线分别穿过离边界最近的正例和负例。
- **支持向量（Support Vectors）**：恰好落在间隔边界上的那些样本点。它们是决定最终决策边界的关键样本；移动其他远离边界的样本不会影响模型，但移动支持向量会改变边界。
- **最大化间隔**：SVM 的优化目标可以形式化为：
  $$
  \begin{aligned}
  \min_{w,b} \quad & \frac{1}{2} \|w\|^2 \\
  \text{s.t.} \quad & y_i(w^T x_i + b) \geq 1, \quad i=1,\dots,n
  \end{aligned}
  $$
  其中约束条件保证了所有样本都被正确分类，且间隔至少为 $\frac{2}{\|w\|}$。

### 1.3 鲁棒性
- 因为 SVM 只依赖于支持向量，而对远离边界的样本不敏感，所以它对**异常值（outliers）**具有一定的容忍度。
- 最大化间隔的策略使得模型在未知数据上的预测更稳定，**泛化误差更小**。

### 1.4 核函数（Kernel Function）
当数据在低维空间中**线性不可分**时，SVM 通过核函数将数据映射到高维特征空间，从而在高维空间中寻找线性超平面。

**常用核函数**：
- **线性核（Linear Kernel）**：$K(x, z) = x^T z$，适用于线性可分场景。
- **多项式核（Polynomial Kernel）**：$K(x, z) = (x^T z + c)^d$
- **高斯核 / RBF 核（Radial Basis Function）**：$K(x, z) = \exp\left(-\frac{\|x-z\|^2}{2\sigma^2}\right)$
  - 这是最常用的核函数，能把数据映射到无限维空间，适用于复杂的非线性边界。

**核技巧（Kernel Trick）**：不需要显式计算高维映射 $\phi(x)$，而是直接在原始空间中通过核函数计算高维空间的内积，大大降低了计算复杂度。

### 1.5 软间隔（Soft Margin）
现实数据往往存在噪声，硬间隔（要求所有样本完全分对）会导致过拟合。软间隔允许少量样本被错分或落在间隔内：
- 引入**松弛变量** $\xi_i \geq 0$ 和**惩罚参数 $C$**：
  $$
  \min_{w,b,\xi} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i
  $$
- **$C$ 的作用**：
  - $C$ 很大：对错误惩罚重，间隔变窄，容易过拟合。
  - $C$ 很小：允许更多错误，间隔变宽，模型更平滑，泛化能力更强。

## 二、感知机（Perceptron）

感知机是神经网络和 SVM 的前身，是一种二分类线性模型。
- **模型**：$f(x) = \text{sign}(w^T x + b)$
- **策略**：最小化误分类点到超平面的总距离（损失函数）。
- **算法**：随机梯度下降（SGD），逐个遍历样本，遇到误分类点即更新参数：
  $$
  w \leftarrow w + \eta y_i x_i, \quad b \leftarrow b + \eta y_i
  $$
- **局限**：只能处理线性可分问题；当数据线性不可分时，算法不收敛。

> 与 SVM 的区别：感知机只关心“能否分开”，找到的解不唯一；SVM 通过最大化间隔找到唯一的最优解。

## 三、激活函数

### 3.1 激活函数的性质
一个好的激活函数通常应满足以下性质：

1. **连续且可导（非线性）**
   - 如果激活函数是线性的，多层网络将等价于单层网络，失去深度学习的意义。非线性激活函数赋予网络拟合复杂函数的能力。

2. **激活函数及其导函数要简单**
   - 便于计算，提高前向传播和反向传播的效率。

3. **激活函数及其导函数值域在一个合适的区间**
   - 值域过大或过小容易引发**梯度爆炸**（Gradient Exploding）或**梯度消失**（Gradient Vanishing）问题。

4. **单调递增**
   - 保证损失函数是凸函数或近似凸的，便于优化收敛。

### 3.2 常见的激活函数

#### S 型（Sigmoid 族）
- **Sigmoid 函数**
  $$\sigma(x) = \frac{1}{1 + e^{-x}}$$
  - 输出范围 $(0, 1)$，适合概率输出。
  - **缺点**：
    - **非零中心化**：输出值恒为正，导致后续层输入全为正，梯度更新时只能同向变化，造成 **zig-zag 现象（bias shift）**，收敛变慢。
    - **梯度消失**：当 $|x|$ 较大时，导数趋近于 0，深层网络中梯度逐层衰减。

- **Tanh 函数**
  $$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$
  - 输出范围 $(-1, 1)$，是**零中心化**的，相比 Sigmoid 收敛更快。
  - 但仍存在梯度消失问题。

> **BN / LN 的作用**：Batch Normalization 和 Layer Normalization 可以缓解非零中心化带来的 bias shift 问题，加速收敛。

#### 斜坡型（ReLU 族）
- **ReLU 函数（Rectified Linear Unit）**
  $$f(x) = \max(0, x)$$
  - 优点：计算简单，梯度不会饱和（正区间导数为 1），有效缓解梯度消失，收敛速度快。
  - 缺点：
    - **死亡神经元问题（Dying ReLU）**：当输入为负时，梯度恒为 0，神经元可能永远无法被激活。

- **Leaky ReLU**
  $$f(x) = \max(\alpha x, x), \quad \alpha \in (0, 1)$$
  - 在负区间引入小的斜率 $\alpha$（如 0.01），避免神经元完全死亡。

- **PReLU（Parametric ReLU）**
  - 与 Leaky ReLU 类似，但负区间的斜率 $\alpha$ 是可学习的参数。

- **ELU（Exponential Linear Unit）**
  $$f(x) = \begin{cases} x, & x > 0 \\ \alpha(e^x - 1), & x \leq 0 \end{cases}$$
  - 在负区间平滑逼近零，输出均值更接近 0，同时避免了死亡神经元问题。

- **Softplus 函数**
  $$f(x) = \ln(1 + e^x)$$
  - 是 ReLU 的平滑版本，处处可导，但计算量稍大。

## 四、人工神经网络的三元素

构建一个神经网络需要三个基本要素：

1. **数据（Data）**
   - 网络学习的对象，包括输入特征和对应的标签。

2. **网络拓扑结构（Architecture）**
   - 神经元的组织方式、层数、每层神经元数量、连接方式等。

3. **学习算法（Learning Algorithm）**
   - 定义如何调整网络参数以最小化损失函数，如前向传播、反向传播、梯度下降及其变体（SGD、Adam 等）。

---

## 五、参数含义

- **$w$（权重，Weight）**
  - 表示神经元之间连接的**强弱**。$w$ 越大，说明前一个神经元对后一个神经元的影响越大；$w$ 为负表示抑制作用。

- **$b$（偏置，Bias）**
  - 表示神经元的**激活阈值**。可以看作是神经元“容易兴奋”还是“难兴奋”的基准线。$b$ 越大，神经元越容易被激活。
