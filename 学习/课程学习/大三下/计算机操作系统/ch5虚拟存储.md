置换算法

optimal:最佳置换算法,无法实现,常用于评判其他算法
FIFO:先进先出算法,采用队列或者循环队列实现
LRU():最近最少使用算法,采用栈或者链表实现,过去的已知,向前看,未来的未知,看值的大小
    - 硬件配置:
        - 移位寄存器
        - 使用栈保存
    - 软件配置:
LFU(least frequency used):最不经常使用算法,采用计数器实现,每一位求和
clock:
    - 简单的 clock 置换算法:只加一个使用位,每次访问时将使用位设置为 1,当需要置换时,扫描页表,找到第一个使用位为 0 的页进行置换,如果使用位为 1,则将其设置为 0 并继续扫描
        - 使用位
    - 加强的 clock 置换算法:在简单 clock 的基础上,增加了一个修改位,当需要置换时,优先选择使用位为 0 且修改位为 0 的页进行置换,如果没有这样的页,则选择使用位为 0 且修改位为 1 的页进行置换,如果仍然没有,则选择使用位为 1 的页进行置换
        - 访问位,修改位
页面缓冲算法(PBA):在 clock 置换算法的基础上,增加了一个页面缓冲区,当需要置换时,首先将要置换的页放入缓冲区,然后扫描页表,找到第一个使用位为 0 的页进行置换,如果使用位为 1,则将其设置为 0 并继续扫描,如果在扫描过程中找到的页已经在缓冲区中,则直接将其置换掉
