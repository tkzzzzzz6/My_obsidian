查询过程

结合你提供的这页 PPT 截图（查询输入接口）以及我们上一回讨论的内容（查询输出接口），可以看出这套微机原理课程的硬件设定非常经典统一：
* **状态端口**：`5001H`
* **数据端口**：`5000H` （通过 `dec dx` 实现地址切换）

下面我为你将这**两个接口**的汇编代码整理在一起，并保持与 PPT 完全一致的代码风格和注释格式，方便你直接复习或写在试卷上。

### 1. 查询输入接口 (Polling Input)
**硬件假设**：状态位 D0 = 1 表示外设数据已就绪；D0 = 0 表示未就绪。

```asm
          mov dx, 5001h   ; DX指向状态端口
status:   in al, dx       ; 读状态端口
          test al, 01h    ; 测试状态位D0 (01H = 00000001B)
          jz status       ; D0=0，未就绪，继续查询

          dec dx          ; D0=1，就绪，DX改指数据端口 (5000H)
          in al, dx       ; 从数据端口输入数据
          
          mov buf, al     ; (可选) 将读取到的数据存入内存变量 buf 中
```

---

### 2. 查询输出接口 (Polling Output)
**硬件假设**：状态位 D7 = 0 表示外设空闲（可接收数据）；D7 = 1 表示忙碌。

```asm
          mov dx, 5001h   ; DX指向状态端口
status:   in al, dx       ; 读状态端口
          test al, 80h    ; 测试状态位D7 (80H = 10000000B)
          jnz status      ; D7=1，忙碌，继续查询

          dec dx          ; D7=0，空闲，DX改指数据端口 (5000H)
          mov al, buf     ; 将准备发送的数据(从变量 buf) 放入 AL 寄存器
          out dx, al      ; 向数据端口输出数据
```

### 核心对比记忆口诀
* **输入看最低位，输出看最高位**：输入通常 `test al, 01h`，输出通常 `test al, 80h`（具体视题目电路图而定，但这是最常见的默认规则）。
* **输入用 JZ，输出用 JNZ**：输入是“等于 0 就等 (JZ)”，输出是“不等于 0 就等 (JNZ)”。
* **最后一步动作**：输入是把数据拿进来（`IN AL, DX`），输出是把数据推出去（`OUT DX, AL`）。
