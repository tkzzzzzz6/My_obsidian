面向对象是一种把现实中的事物抽象成“对象”的编程思想。对象一般包含属性和方法两部分。属性就是对象具有的数据，方法就是对象能完成的操作。比如在程序中表示一个学生，可以有姓名、学号、成绩这些属性，也可以有学习、考试、显示信息这些方法。面向对象不是单纯地关注程序一步一步怎么执行，而是更关注程序里有哪些对象、对象之间有什么关系、每个对象负责什么功能。

面向对象是一种以“对象”为中心的编程思想。它把现实中的事物抽象成程序中的对象，对象一般包含属性和方法。比如学生可以有姓名、成绩等属性，也可以有显示信息、修改成绩等方法。类可以理解成创建对象的模板，对象就是类的具体实例。如在 C++ 中可以定义 `Student` 类，再创建 `Student s1;`；在 Python 中可以用 `class Student:` 定义类，再用 `s1 = Student()` 创建对象。Python 中还可以使用 `__init__` 方法，在创建对象时自动初始化姓名、成绩等属性，这样创建对象会更方便。

面向对象的主要特点有封装、继承和多态。封装就是把数据和操作数据的方法放在类里面，并限制外部随便访问数据。C++ 中可以把成绩设为 `private`，再通过 `setScore()` 判断成绩是否在 0 到 100 之间。Python 中虽然没有严格的 `private`，但也可以通过命名习惯或属性方法实现类似效果。比如可以使用 `@property` 把方法像属性一样访问，同时在设置成绩时判断成绩是否合法，这也体现了封装的思想。继承就是子类可以使用父类已有的属性和方法，比如 `Student` 类继承 `Person` 类后，就可以直接拥有姓名、年龄等信息。在 Python 中，子类还可以用 `super()` 调用父类的方法，避免重复写代码。多态就是同一个方法在不同对象中有不同表现，比如学生和老师都可以有 `introduce()` 方法，但输出内容不同。C++ 中常用虚函数实现多态，Python 中只要不同对象有同名方法，就可以用统一方式调用。

面向对象的优点是结构清楚、代码复用性强、方便维护和扩展。比如写学生成绩管理系统时，如果只用列表或字典保存信息，代码多了容易乱；如果定义 `Student` 类，把姓名、成绩和显示信息的方法放在一起，程序就更好理解。在 Python 中，还可以使用 `__str__` 方法规定对象被打印时显示什么内容，比如打印学生对象时直接显示学生姓名和成绩，而不是显示一串默认地址。这样对象使用起来更自然，也更方便调试。写图书管理系统时，也可以把图书、用户、借阅记录分别设计成类，这样以后增加功能时不用把所有代码都重新改一遍。
