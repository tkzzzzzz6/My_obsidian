蓝桥学院的冬季旅行队终于到达了冰雪奇缘大世界。只见门口大招牌上挂着一个长度为 $N$ 的小写字符串 $S$，经过了解，原来冰雪奇缘大世界每日都会推出一个回文字符串挑战，挑战成功即可获得一份精美礼品。挑战规则如下：

- 可以任意重排字符串 $S$ 的字符顺序。
- 重排后，需要将整个字符串切割为若干个连续的回文子串（每个子串必须是回文）。
- 求出切割后最少的回文子串数量。

现在请你帮助旅行队解决这个问题，输出这个最小数量。

**回文串：**是指一个字符串，如果从左到右读取和从右到左读取的结果完全相同，则称为回文串。

### 输入格式

第一行包含一个整数 $N$（$1 \leq N \leq 10^5$），表示字符串的长度。

第二行包含一个长度为 $N$ 的小写字母字符串 $S$。

### 输出格式

输出一个整数，表示最少的回文子串数量。

### 样例输入1

```
3
aba
```

### 样例输出1

```
1
```

### 样例输入2

```
4
acbb
```

### 样例输出2

```
2
```

### 说明

对于样例 $1$，无需切割，$S$ 本身即为回文串。

对于样例 $2$，可以切割为 `bab` 和 `c` 两个回文串。
