# 前言

1. go是静态编译型语言
2. 在语言级别支持协程
3. 代码风格强制统一
4. 不提供重载,反对虚函数,采用组合文法提供继承,放弃构造函数和析构函数,提供非侵入性接口

# 第一章初识GO语言

1. GO语言的语言特性
    1. 自动垃圾回收GC
    2. 更丰富的内置类型:字典map和数据切片slice
    3. 函数多返回值
    4. 错误处理:defer,panic,recover
    5. 匿名函数和闭包
        ```go
        <!-- 定义一个名为f的匿名函数 -->
        f := func(x,y int){
            return x+y
        }
        ```
    6. 类型和接口
    7. 并发编程
    8. 反射
