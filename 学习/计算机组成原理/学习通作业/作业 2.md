一. 阅读理解（共3题，60分）
1. (阅读理解) C语言中允许无符号数和有符号整数之间的转换， 下面是一段C语言代码:
int x =-1;
unsigned u=2147483648;
printf (“x=%u=%d\n”，x，x);
printf (“u=%u=%d\n”，u，u);

(1) (简答题)
给出在32位计算机中上述程序段的输出结果。
**答：**
在32位计算机中，输出结果如下：
`x=4294967295=-1`
`u=2147483648=-2147483648`

(2) (简答题)

分析上述结果出现的原因。
**答：**
*   对于 `int x = -1;`：
    *   在32位系统中，`int` 类型的 `-1` 在内存中以补码形式存储为 `0xFFFFFFFF`（即二进制的32个1）。
    *   当使用 `%u` 格式符打印时，该 `0xFFFFFFFF` 被解释为无符号整数，其值为 `2^32 - 1 = 4294967295`。
    *   当使用 `%d` 格式符打印时，该 `0xFFFFFFFF` 被正确解释为有符号整数，其值为 `-1`。

*   对于 `unsigned u = 2147483648;`：
    *   `unsigned int` 类型的 `2147483648` 在内存中存储为 `0x80000000`（即二进制的 `1000...000`，最高位为1）。
    *   当使用 `%u` 格式符打印时，该 `0x80000000` 被正确解释为无符号整数，其值为 `2147483648`。
    *   当使用 `%d` 格式符打印时，该 `0x80000000` 被解释为有符号整数。在补码表示中，最高位为1表示负数。在32位有符号整数中，`0x80000000` 代表最小的负数，即 `-2^31 = -2147483648`。这是因为 `2147483648` 大于32位有符号整数的最大正值 (`2^31 - 1 = 2147483647`)，因此在按有符号数解释时发生了溢出。

2. (阅读理解) 将下列十进制数表示成浮点规格化数，阶码4位，尾数10位，各含1位符号，阶码和尾数均用补码表示。
(1) (填空题)
57/128的4位阶码 = （ **1111** ），10位尾数 = （ **0111001000** ）。
**解答过程：**
*   **转换为二进制小数：** 57/128 = 0.4453125 = `0.0111001_2`
*   **规格化：** `0.111001_2` × `2^-1`
*   **阶码 (Exponent)：** `E = -1`。4位补码表示 `-1` 为 `1111`。
*   **尾数 (Mantissa)：** 数值为 `0.111001_2`。由于是正数，符号位为 `0`。10位尾数（包含1位符号位和9位数值位）表示为 `0.111001000`。

(2) (填空题)

-69/128的4位阶码 = （ **0000** ），10位尾数 = （ **1.011101100** ）。
**解答过程：**
*   **转换为二进制小数的绝对值：** 69/128 = 0.5390625 = `0.1000101_2`
*   **规格化：** `N = -0.1000101_2` × `2^0`
*   **阶码 (Exponent)：** `E = 0`。4位补码表示 `0` 为 `0000`。
*   **尾数 (Mantissa)：** 数值为 `-0.1000101_2`。由于是负数，符号位为 `1`。
    *   正数 `0.100010100` (10位，补齐9位小数)
    *   按位取反 `1.011101011`
    *   末位加1 `1.011101100`
    *   所以10位尾数（补码）为 `1.011101100`。

### 3. (阅读理解) 设二进制浮点数的阶码为3位，尾数是7位。用模2补码写出它们所能表示的最大正数、最小正数、最大负数和最小负数。

**阶码 (3位补码)：** 可表示的范围是 `100` (-4) 到 `011` (3)。
**尾数 (7位补码，且为规格化小数形式)：**
*   最大正尾数： `0.111111` (约等于 `1 - 2^-6`)
*   最小正尾数： `0.100000` (`0.5`)
*   最大负尾数 (最接近0的负数)： `1.111111` (`-2^-6`)
*   最小负尾数 (离0最远的负数)： `1.000000` (`-1`)

(1) (填空题)

最大正数的3位阶码为（ **011** ），7位尾数为（ **0.111111** ）。
**解释：** 为了得到最大正数，需取最大的正尾数 `0.111111` 和最大的正阶码 `011` (十进制3)。

(2) (填空题)

最小正数的3位阶码为（ **100** ），7位尾数为（ **0.100000** ）。
**解释：** 为了得到最小正数，需取最小的规格化正尾数 `0.100000` 和最小的阶码 `100` (十进制-4)。

(3) (填空题)
最大负数的3位阶码为（ **100** ），7位尾数为（ **1.111111** ）。
**解释：** 为了得到最大负数（最接近0的负数），需取最接近0的负尾数 `1.111111` (十进制 `-2^-6`) 和最小的阶码 `100` (十进制-4)。

(4) (填空题)

最小负数的3位阶码为（ **011** ），7位尾数为（ **1.000000** ）。
**解释：** 为了得到最小负数（离0最远的负数），需取离0最远的负尾数 `1.000000` (十进制 `-1`) 和最大的阶码 `011` (十进制3)。

4. (简答题)
分析下列几种情况下所能表示的数据范围分别是多少？

1)16位无符号数；
**答：** `0` 到 `2^16 - 1`，即 `0` 到 `65535`。

2)16位原码定点小数；
**答：** 1位符号位，15位小数位。
   *   最大正数： `0.111111111111111_2` (`1 - 2^-15`)
   *   最小负数： `1.111111111111111_2` (`-(1 - 2^-15)`)
   *   范围： `-(1 - 2^-15)` 到 `(1 - 2^-15)` (包含 `0`)。

3)16位补码定点小数；
**答：** 1位符号位，15位小数位。
   *   最大正数： `0.111111111111111_2` (`1 - 2^-15`)
   *   最小负数： `1.000000000000000_2` (`-1`)
   *   范围： `-1` 到 `(1 - 2^-15)`。

4)16位补码定点整数。
**答：** 1位符号位，15位数值位。
   *   最小负数： `1000000000000000_2` (`-2^15` = -32768)
   *   最大正数： `0111111111111111_2` (`2^15 - 1` = 32767)
   *   范围： `-32768` 到 `32767`。

## 三. 填空题（共1题，20分）

### 5. (填空题) 与单精度浮点数43940000H对应的十进制数是（ **296.0** ）。
**解答过程：**
*   单精度浮点数采用IEEE 754标准，32位。
*   `43940000H` 转换为二进制： `0100 0011 1001 0100 0000 0000 0000 0000`

*   **符号位 (S)：** 第31位，为 `0` (表示正数)。
*   **阶码 (E)：** 第30-23位，为 `10000111`。
    *   转换为十进制： `128 + 4 + 2 + 1 = 135`。
    *   根据IEEE 754标准，单精度浮点数的阶码需要减去一个偏移量 (Bias)，Bias = `127`。
    *   实际阶码 = `135 - 127 = 8`。
*   **尾数 (M)：** 第22-0位，为 `00101000000000000000000`。
    *   由于是规格化浮点数，尾数部分需要加上一个隐藏的 `1`。
    *   有效位为 `1.00101` (后续的0不影响数值)。
    *   转换为十进制： `1 + 0*(2^-1) + 0*(2^-2) + 1*(2^-3) + 0*(2^-4) + 1*(2^-5)`
    *   `1 + 0 + 0 + 0.125 + 0 + 0.03125 = 1.15625`。

*   **最终结果：** `(-1)^S × 1.M × 2^实际阶码`
    *   `(-1)^0 × 1.15625 × 2^8`
    *   `1 × 1.15625 × 256`
    *   `1.15625 × 256 = 296.0`。
