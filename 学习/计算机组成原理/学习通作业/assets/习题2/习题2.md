(3) (简答题)
“LDA X” 指令执行通路分析

在该处理器指令集中，“LDA X” 为 “主存读” 指令（功能定义：将主存地址 X 对应的存储单元内容送入累加器 AC，即 ( X )→AC）。请结合硬件架构，描述该指令执行阶段的完整数据通路（含地址传输、数据读取、运算器交互的全链路）。

**分析：**
`LDA X` 是取数指令，功能是将内存地址 X 的内容加载到累加器 AC。此时指令已在 IR (b) 中，地址码 X 位于 b 中。

1. **送地址** ：将指令寄存器 (b) 中的地址码 X 送入地址寄存器 (c)。
2. **读数据** ：主存 (M) 根据地址 X 读出数据，送入数据寄存器 (a)。
3. **执行加载** ：数据从 (a) 经过 ALU（通常由 ALU 进行透传操作，即加 0 或直接传送）送入累加器 AC。

指令寄存器IR(b) → 地址寄存器MAR(c) → 主存储器M→ 数据寄存器MDR(a) → 运算器ALU → 累加器AC

(4) (简答题)
“ADD Y” 指令执行通路分析

“ADD Y” 为 “主存加法” 指令（功能定义：将累加器 AC 当前值与主存地址 Y 对应的存储单元内容相加，结果回存至 AC，即 (AC)+( Y )→AC）。请基于硬件模块的连接逻辑，描述该指令执行阶段的数据传输与运算通路。

**分析：**
`ADD Y` 是加法指令，功能是将 AC 的当前值与内存地址 Y 的内容相加，结果存回 AC。

1. **送地址** ：将指令寄存器 (b) 中的地址码 Y 送入地址寄存器 (c)。
2. **读操作数** ：主存 (M) 根据地址 Y 读出操作数，送入数据寄存器 (a)。
3. **执行运算** ：累加器 AC 的内容和数据寄存器 (a) 的内容同时送入 ALU 进行加法运算，运算结果由 ALU 输出并写回 AC。

**答案：**

* 取操作数：指令寄存器IR(b) → 地址寄存器MAR(c) → 主存储器M → 数据寄存器MDR(a)
* 运算回写：(累加器AC，数据寄存器MDR(a)) → 运算器ALU → 累加器AC

  状态寄存器由ALU更新

(5) (简答题)
“STA Z” 指令执行通路分析

“STA Z” 为 “主存写” 指令（功能定义：将累加器 AC 当前值写入主存地址 Z 对应的存储单元，即 (AC)→Z）。请结合图中信息流向，描述该指令执行阶段的地址准备、数据写回通路。

**分析：**
`STA Z` 是存数指令，功能是将 AC 的内容写入内存地址 Z。

1. **送地址** ：将指令寄存器 (b) 中的地址码 Z 送入地址寄存器 (c)。
2. **送数据** ：将累加器 AC 中的数据送入数据寄存器 (a)（图中 AC 有指向 a 的箭头）。
3. **写内存** ：将 (a) 中的数据写入主存 (M) 中由 (c) 指向的单元。

**答案：**

* 地址准备：指令寄存器IR(b) → 地址寄存器MAR(c) → 主存储器M(地址端)
* 数据写回：累加器AC → 数据寄存器MDR(a) → 主存储器M(数据端),在操作控制器的写控制信号为1时,吧数据寄存器(a)的内容写入到地址寄存器(c)指定的内存中,完成写主存操作

(1) (简答题)
取指周期微操作序列分析

指令取指是 CPU 指令执行的首个阶段，需完成 “从主存读取指令、送入指令寄存器并完成程序计数器自增” 的硬件逻辑。请结合图中数据通路，推导该阶段的微操作执行序列（需明确各硬件模块的信号传输与控制逻辑，以 “部件操作→部件操作” 的形式描述）。

 **目标** ：将 PC 的内容作为地址送给主存，读出指令存入 IR，并使 PC+1。

* **分析** ：
* PC 在寄存器堆中，要送到 MAR，必须走：`PC → LA/LB → ALU → 移位器 → 总线 → MAR`。
* PC 自增通常在 CPU 内部完成，可以利用 ALU 进行 +1 运算，结果写回 PC。
* 内存读出的指令经 MDR 送入 IR。
* 取指周期 = PC 给地址 → 内存给指令 → IR 装指令 → PC 通过 ALU 自增。

 **答案** ：

| 节拍         | 微操作                                              |
| ------------ | --------------------------------------------------- |
| **T0** | **MAR ← PC**                                 |
| **T1** | **MDR ← M[MAR]**                             |
| **T2** | **IR ← MDR**                                 |
| **T3** | **LA ← PC；LB ← 1；PC ← LA + LB(PC=PC+1)** |

对于ADD R₁, (R₂)指令，取数阶段需完成 “以 R₂内容为地址，读取主存对应单元数据” 的功能。请基于硬件模块的连接关系，推导该阶段的微操作执行序列（需覆盖地址传输、主存访问、数据暂存的全链路）。

**答案** ：

| **T4** | **MAR ← R2**     |

(3) (简答题)
加法周期微操作序列分析

加法运算阶段需完成 “R₁数据与取数阶段获取的主存数据相加，并暂存结果” 的功能。请结合 ALU、寄存器组等模块的交互逻辑，推导该阶段的微操作执行序列（需明确运算器的输入来源、运算过程及结果存储逻辑）。

 **目标** ：将 `R₁`（被加数）与 `MDR` 中的数据（加数）相加，结果写回。

* **分析** ：
* **操作数1** ：`R₁` 在寄存器组中，直接送入 `LA`。
* **操作数2** ：刚才取出的数在 `MDR` 中。需要从 `MDR` 送到 ALU 的另一端 `LB`。
  * *路径细节* ：图中显示 MDR 连在总线上，要进 `LB`，通常路径是 `MDR → Bus → LB`（注意：虽然图中箭头主要画的是寄存器堆向上指，但在单总线结构中，Bus通常都能连通 ALU 的输入锁存器，或者通过寄存器堆的内部通路）。
* **运算** ：ALU 执行加法。
* **回写** ：结果穿过移位器，通过 Bus 写回 `R₁`。

 **答案** ：

1. **MDR → Bus → LB** （将取出的主存操作数送入运算器输入端B）
2. **R₁ → LA** （将寄存器R₁数据送入运算器输入端A）
3. **ALU(A+B) → 移位器 → Bus → R₁** （执行加法运算，结果经总线写回R₁）
