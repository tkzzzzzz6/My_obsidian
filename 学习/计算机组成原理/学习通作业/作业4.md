## 第二题
![1765875228346.png](https://tk-pichost-1325224430.cos.ap-chengdu.myqcloud.com/blog/1765875228346.png)
![1765875272419.png](https://tk-pichost-1325224430.cos.ap-chengdu.myqcloud.com/blog/1765875272419.png)
这题的关键点有两个：

1. **转移指令是相对寻址**：转移目标地址 = **(当前PC取完该指令后的PC值)** + **相对位移量disp**
    
2. **CPU每取1个字节，PC自动+1**。该转移指令共3字节，所以**取完指令后**
    
    PC_{\text{after}} = PC_{\text{before}} + 3
    

并且相对位移量 disp 用 **16位补码** 表示，其中：

- 第2字节 = disp 的 **低8位**
    
- 第3字节 = disp 的 **高8位**
    

---

## **通用解题步骤（套公式）**

  

给定：PC当前值 = PC，目标地址 = T

1. 取完3字节后的PC：
    
    PC_{\text{after}} = PC + 3
    
2. 计算相对位移（有符号）：
    
    disp = T - PC_{\text{after}}
    
3. 把 disp 写成 **16位补码**（十六进制 4 位）
    
4. **低8位给第2字节，高8位给第3字节**
    

---

## **(1) PC=256(十进制)，转移到290(十进制)**

  

**步骤1：**

PC_{\text{after}} = 256 + 3 = 259

  

**步骤2：**

disp = 290 - 259 = 31

  

**步骤3：** 31 的16位补码就是普通二进制：

31_{10} = 001F_{16}

  

**步骤4：拆成低8位/高8位**

- 低8位（第2字节）= **1Fh**
    
- 高8位（第3字节）= **00h**
    

  

✅ **参考答案：第2字节 = 1FH，第3字节 = 00H**

---

## **(2) PC=128(十进制)，转移到110(十进制)**

  

**步骤1：**

PC_{\text{after}} = 128 + 3 = 131

  

**步骤2：**

disp = 110 - 131 = -21

  

**步骤3：把 -21 写成16位补码**

先写 +21：

21_{10} = 0015_{16}

求补码（取反+1）：

- 取反：FFEA
    
- +1：FFEB
    

  

所以：

-21 = FFEB_{16}

  

**步骤4：拆成低8位/高8位**

- 低8位（第2字节）= **EBh**
    
- 高8位（第3字节）= **FFh**
    

  

✅ **参考答案：第2字节 = EBH，第3字节 = FFH**

---

### **最终汇总**

- (1) **1FH，00H**
    
- (2) **EBH，FFH**
