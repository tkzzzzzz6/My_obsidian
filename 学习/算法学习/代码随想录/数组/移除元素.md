数组的定义连续的类型相同的元素的集合

元素覆盖

cpp 中使用 erase() 删除元素,实际上没有删除,size()减少是因为内部有计数器,才事项了(1)的复杂度

方法 1:暴力后面覆盖前面的,两个 for 循环,复杂度 O(n^2)

```cpp
void earse_num1(vector<int> &arr, int e){
    for(int i = 0; i < arr.size(); ++i){
        if(arr[i] == e){
            for(int j = i+1; j < arr.size(); ++j){
                arr[j-1] = arr[j];
            }
            arr.pop_back();  // 删除最后一个元素
            --i;  // 重新检查当前位置
        }
    }
}
```

方法 2:快慢双指针,一个指针 i 遍历数组,另一个指针 j 记录不重复元素的个数,当 nums[i] != val 时,nums[j] = nums[i],j++ 最后返回 j 就是新数组的长度,复杂度 O(n)

fast:获取新数组的元素
slow:新数组需要更新的位置

```cpp
void earse_num1(vector<int> &arr,int e){
    int slow = fast = 0;
    for(int fast = 0;fast < arr.size();++fast){
        if(arr[fast] != e){
            arr[slow] = arr[fast]; //等效于 arr[slow++] = arr[fast];
            ++slow;
        }
    }
}
```
