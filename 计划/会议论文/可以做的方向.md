# agent memory
[2605.13716v1](https://arxiv.org/pdf/2605.13716v1)

- [ ] 如何提高模型的灵活应变的能力
你提到的“走后门变通的能力”，在学术界和工业界通常不会用这么“江湖”的词，它对应的专业研究方向是 **策略性推理（Strategic Reasoning）**、**自我修正（Self-Correction）** 以及 **约束满足（Constraint Satisfaction）**。

简单来说，这种能力是指：**当模型发现常规路径（正面攻击）走不通时，能够自动寻找替代方案、利用规则漏洞或绕过障碍来达成目标的能力。**

在论文中，这些变通能力通常体现为以下技巧：

1. **重构问题（Problem Reframing）：** 当模型发现直接算算不出来时，它会说“让我们换个角度看这个问题”。
    
2. **退而求其次（Backtracking）：** 发现逻辑错误，主动删除之前的推理，重新从上一步开始。
    
3. **利用工具（Tool Use）：** 当脑算不行时，主动要求调用 Python 脚本（走工具的后门）来解决问题。
    
4. **语义逃逸（Semantic Escape）：** 使用类比、隐喻等方式绕过词汇限制。
- **Reward Hacking**（奖励作弊，这是模型最极端的“走后门”表现）
    
- **Self-Correction Loop**（自我修正环）
    
- **Inference-time Compute**（推理时算力）
