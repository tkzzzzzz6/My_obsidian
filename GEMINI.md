# GEMINI.md

## Directory Overview

This directory is an [Obsidian](https://obsidian.md/) vault, serving as a personal knowledge base. It is structured to organize notes on a variety of subjects, including academic research, coursework, technical experiments, and personal interests. The content is primarily in Markdown format.

## Key Directories and Their Purpose

*   `.obsidian/`: This directory contains the configuration files for the Obsidian vault, including settings for plugins, themes, and core application preferences.
*   `科研/` (Scientific Research): This section houses notes and materials related to academic research. Current topics include spatial transcriptomics, Vision-Language Models (VLM), and specific research papers.
*   `学习/` (Learning): This is the largest section, containing study notes across various domains:
    *   **Computer Science:** Notes on databases, Linux, computer organization, and data structures & algorithms (including LeetCode problems).
    *   **Coursework:** Materials for courses like "Labor Education", "Database Technology", and "Algorithm Analysis and Design".
    *   **Certifications:** Preparation notes for computer-related exams.
    *   **Interests:** Notes on game development, large model fine-tuning, and English articles.
*   `实验/` (Experiments): Contains notes and documentation for hands-on technical experiments, such as setting up database environments.
*   `杂项/` (Miscellaneous): A collection of miscellaneous notes, primarily focused on computer environment configuration and troubleshooting.
*   `Excalidraw/`: Stores drawings and diagrams created with the Excalidraw plugin for Obsidian, which is used for visual note-taking and whiteboarding.
*   `tools/`: Contains utility scripts. For example, `pptx_to_pdf.py` is a Python script to convert PowerPoint presentations to PDF files.

## Usage

This vault is intended to be used with the Obsidian application. The user creates, edits, and links notes in Markdown to build a personal knowledge graph. The folder structure provides a high-level organization, while Obsidian's features like backlinks and graph view allow for more networked and non-linear connections between ideas.
