证明材料:
1. 办理护照以及等待时间截图或签证申请进度截图(这两个有一个正在办理就用哪个)
2. 学校在读证明
3. 必要时的签证预约记录


说明首次出国导致时间风险 → 解释为什么需要 proxy → 说明 proxy 与论文关系 → 提供证明材料。这种结构在国际会议中是常见的，因此可以使用。不过需要注意一点：很多 IEEE 会议更容易接受的是“签证或旅行限制”类理由，而“首次办理护照流程可能来不及”这种理由虽然真实，但说服力略低。所以建议把重点放在签证处理时间的不确定性，而不是护照办理本身。

目前正在办理护照和签证，但由于申根签证审批时间存在不确定性，可能无法在会议前获得签证，因此希望提前申请 proxy 作为备用方案。这样表述会更容易被接受。

第三部分是代理人的关系说明，这一部分写得是合理的，但可以稍微强化一点。会议最关心的是代理人是否真正理解论文并能够回答问题，因此建议在关系描述中加入两个信息：一是代理人与论文作者的学术关系，例如曾经在同一实验室或参与过相关研究讨论；二是代理人的研究方向与论文主题接近。这样可以让会议相信代理展示不会影响学术质量。

第四部分是承诺条款。你们提出“如果签证下来就自己参会”这一点是非常好的，因为它说明 proxy 只是备用方案（backup plan）。不过建议写得更明确一点，例如说明如果签证在会议前获得，你们将亲自参会并由作者本人报告论文。
