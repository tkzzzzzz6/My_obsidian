# 基于深度学习的双域CT重建方法研究

## 一、论文基本信息
《基于深度学习的双域CT重建方法研究》，作者张谊坤，东南大学计算机科学与工程学院博士学位论文（June 2023）。 

关键词:聚焦双域处理、深度迭代重建/展开、GAN、稀疏/有限角度 CT 与 DECT、先验约束。  

## 二、研究背景与问题定义
1. 低剂量、稀疏角度与有限角度采样会导致测量数据退化，噪声和伪影明显。  
2. DECT 具有材料分辨能力，但依赖昂贵专用硬件，限制临床普及与设备兼容。

问题聚焦于非理想采样条件下，如何联合投影域与图像域信息，将深度学习与成像模型耦合，实现高质量 CT/DECT 重建并抑制伪影、保留细节。

## 三、核心方法 / 模型 / 系统设计
论文提出四条双域路线：  
- 低剂量 CT：CLEAR（双域生成器 + WGAN-GP）。  
- 稀疏角度 CT：DREAM-Net（投影补全/残差感知/图像增强三域约束的深度展开）。  
- 稀疏角度 DECT：CD-Net（互补稀疏扫描 + 双流 ResUNet 双域恢复）。  
- 有限角度 DECT：SPIE-DIR（双域先验增强、跨迭代密集连接与对抗学习）。  

共同思路是把物理一致性与学习先验同时压入投影域与图像域，避免单域方法的过度平滑或数据不一致。

## 四、实验相关
**实验设置**
- AAPM 低剂量 CT + NCI/TCIA 外部患者；含真实腹部体模与真实小鼠数据。  
- DECT：南京东部战区总医院 25 名患者胸腹部数据；抽取 22 名用于有限角度设置。  
- 实验环境：Ubuntu 20.04 / i7-10700K / RTX 3090；低剂量/稀疏角度 CT 使用 PyTorch，DECT 章节使用 TensorFlow。  

**对比方法（Baselines）**
- 低剂量 CT：FBP、TV、RED-CNN、DD-UNet、CLEAR w/o GAN。  
- 稀疏角度 CT：FBP、FBPConvNet、CLEAR、FISTA-Net。  
- 稀疏角度 DECT：PD-Net、ID-Net、SE-CD-Net、CD-Net。  
- 有限角度 DECT：FBP、DD-Net、LEARN++、CD-Net、SPIE-DIR。  

**评估指标**
- MAE、SSIM、PSNR + 视觉评估；DECT 结合 VNC 与碘定量结果。  

**主要实验结果**
| 任务/场景 | 模拟数据（MAE/PSNR/SSIM） | 真实数据（MAE/PSNR/SSIM） | 备注 |
| --- | --- | --- | --- |
| 低剂量 CT | 15.38HU / 40.10dB / 97.71% | 14.15HU / 37.85dB / 95.25% | 体模 |
| 稀疏角度 CT | 12.07HU / 42.07dB / 98.49% | 9.28HU / 37.31dB / 95.63% | 真实小鼠 |
| 稀疏角度 DECT（1/8 采样） | 9.39HU / 44.08dB / 98.99% | - | VNC/碘图更清晰 |
| 有限角度 DECT | 10.83HU / 43.09dB / 98.60% | 10.15HU / 37.74dB / 96.89% | 楔形伪影与 HU 校正改善明显 |

## 五、创新点、贡献总结与改进空间
**主要创新点**：将双域学习系统化到低剂量、稀疏角度与 DECT 多任务，提出 CLEAR/DREAM-Net/CD-Net/SPIE-DIR 等一套成体系的双域重建路线，并在部分场景引入对抗学习与能量域先验。

**论文贡献**：给出从采集方案到重建算法的完整双域框架，并在多数据来源上验证了双域方法在一致性与视觉质量上的优势。

**论文局限性**：模型依赖训练数据分布，跨域泛化仍受限；深度迭代收敛缺乏严格理论保障；工程复杂度与实时性仍有门槛。

**潜在改进方向**：强化物理一致性/自监督约束，探索更轻量的全局建模结构，提升推理速度与跨域泛化能力。

## 六、我的思考与可延伸方向
双域思想适合迁移到 MRI/PET 等逆问题场景，尤其是将物理算子与学习先验解耦并协同训练的方案，值得用于后续项目的框架设计。
