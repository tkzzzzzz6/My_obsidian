基于无损下采样的小目标人体检测算法改进
针对开放水域场景中人体目标距离远、尺度小、纹理细节易在传统下采样过程中丢失的问题，本文拟在目标检测网络中引入基于空间转深度卷积（SPD-Conv）的无损下采样机制。该方法最早由 Sunkara 等人在研究小目标检测问题时提出[35]，其核心思想是将输入特征图的空间信息重排到通道维度，从而在降低分辨率的同时尽可能保留原始像素信息。设输入特征图为 X\in\operatorname{R}^{S\times S\times C_1}（其中 S 为特征图空间尺寸，C_1 为通道数），则 SPD-Conv 可通过间隔采样生成四个子特征图：
&f0,0(x,y,c)=X(2x,2y,c)&f0,1(x,y,c)=X(2x,2y+1,c)&f1,0(x,y,c)=X(2x+1,2y,c)&f1,1(x,y,c)=X(2x+1,2y+1,c)    &&
其中 x,y\in\left\{0,1,\ldots,\frac{S}{2}-1\right\}，c\in\left\{1,2,\ldots,C_1\right\}。
再将四个子特征图在通道维度进行拼接，得到输出特征图：
X^\prime=\mathrm{Concat}\left[f_{0,0},f_{0,1},f_{1,0},f_{1,1}\right],\emsp X^\prime\in\operatorname{R}^{\frac{\mathbb{S}}{\mathbb{2}}\times\frac{\mathbb{S}}{\mathbb{2}}\times\mathbb{4}\operatorname{C}_\mathbb{1}}
该过程被用于替代传统步长卷积或池化层，以解决远距离微小目标特征丢失问题。空间转深度卷积的具体结构如图6所示，而图7展示了溺水检测系统的实时识别与风险预警效果。

3.2.2 基于光流运动熵的异常行为触发机制
在目标检测结果基础上，利用稠密光流对人体区域的运动状态进行建模，并通过运动熵对异常行为进行量化分析。设目标区域内像素点的光流向量为 \mathbit{V}=(v_x,v_y)，其运动幅值为 M=\sqrt{v_x^2+v_y^2}。 将运动幅值离散为 K 个区间，统计各区间的概率分布 p_i，则在给定时间窗口内的光流运动熵定义为：
H_{\mathrm{motion}}=-\sum_{i=1}^{K}p_i\log_2{\left(p_i\right)}
当 H_{motion}>\delta （其中 \delta 为挣扎阈值）时，判定该时间窗口内可能存在高风险异常行为，并截取关键帧及前后时序信息上传云端。
面向人工智能物联网（AIoT）场景设计，广翼智联 FVO1 边缘智能开发板是一款基于高通 QCS6490 平台的高性能边缘计算终端，具备强大的端侧推理能力，在保证低功耗的同时能够提供高效的计算性能，适用于视频分析、智能监控等实时性要求较高的场景 。结合本课题需求，图7是本项目边缘端开发板设备主要用于承担边缘侧视觉感知与初步异常筛选任务，为后续云端语义分析与决策提供高质量输入。

3.2.3 基于视觉语言模型的多模态语义消歧方法
（1）领域微调与知识注入
在通用视觉语言模型基础上，结合开放水域监控场景的领域知识进行领域自适应微调，以提升模型在特定场景下的语义判别能力。不同于传统多任务联合训练方式，本文采用以监督微调（Supervised Fine-Tuning，SFT）为主、行为判别约束为辅的优化策略，其总体损失函数可表示为：
L=L_{\mathrm{SFT}}+\lambda L_{\mathrm{behavior}}
其中：
	L_{\mathrm{SFT}} 表示标准监督微调损失，用于指导模型生成符合任务要求的结构化输出结果，以保持模型的通用视觉语义理解能力；
	L_{\mathrm{behavior}} 表示行为判别约束损失，用于强化模型对溺水与正常行为之间差异的敏感性，提高在复杂水域场景下的异常行为识别能力；
	\lambda 为权重系数，用于平衡生成能力与行为判别能力之间的关系。
（2）多模态输入构建
将视觉 token 与系统提示词 token 拼接为统一输入序列，其形式可表示为：
[Visual_Tokens,Instruction_Tokens,Constraint_Tokens,Format_Tokens]
其中，基于结构化约束指令的多模态语义映射原理如图9所示：
	\mathrm{Visual_Tokens} 由视觉编码器输出，包含空间位置编码 \mathrm{Pos}(v_i)
	\mathrm{Instruction_Tokens} 为任务描述，例如“判断该人员是否溺水”
	\mathrm{Constraint_Tokens} 为领域约束，例如“注意挣扎的肢体动作”
	\mathrm{Format_Tokens} 为输出格式要求，例如“返回风险等级与置信度”
 
图9基于结构化约束指令的多模态语义映射原理示意图
将边缘侧几何检测置信度与云端语义风险等级进行贝叶斯加权融合，若最终风险指数超过阈值则触发报警。首先定义风险先验概率：
P\left(\mathrm{risk}\right)=\frac{N_{\mathrm{risk}}}{N_{\mathrm{total}}}
其中，N_{\mathrm{risk}} 为训练集中异常事件样本数，N_{\mathrm{total}} 为总样本数。然后计算后验概率：
P\left(\mathrm{risk}\middle| G,S\right)\propto P\left(G\middle|\mathrm{risk}\right)\cdot P\left(S\middle|\mathrm{risk}\right)\cdot P\left(\mathrm{risk}\right)
其中：
	G 表示边缘端几何检测结果，置信度为 C_g
	S 表示云端语义判别结果，置信度为 C_s
最终风险指数为：
R=\frac{P\left(\mathrm{risk}\middle| G,S\right)}{P\left(\mathrm{risk}\middle| G,S\right)+P\left(\lnot\mathrm{risk} \middle| G,S\right)}
当系统计算得出的风险指数 R 超过预设阈值 R_{\mathrm{th}} 时，将触发预警机制。系统会通过SMTP协议向预先配置的管理员邮箱发送包含事件详情、风险等级、关键帧截图及地理位置信息的预警邮件，以便安保人员能够及时响应。图10展示了系统通过SMTP发送预警信息至管理员邮箱的示例。

3.2.4 基于无人机仿真的智能调度与响应机制研究
在完成溺水风险识别与语义判别的基础上，进一步探索面向水域安全监测场景的无人机辅助响应机制。为验证视觉感知与语义判别结果在实际救援任务中的应用可行性，本文拟构建基于UE5引擎结合 AirSim + PX4 + QGC 的无人机仿真环境，对无人机巡检与应急响应过程进行模拟验证，如图11所示。需要指出的是，在实际应用中，算法应该根据无人机具体参数和硬件配置进行调整，但在本文的仿真研究阶段，主要关注方法验证和研究思路探索，通过设定合理的仿真参数来评估算法的可行性。
 
图11 AirSim+PX4+QSC无人机仿真环境
在该仿真环境中，AirSim 用于构建水域三维仿真场景并提供物理引擎与传感器数据接口，PX4 作为无人机飞控系统实现飞行控制与任务执行，QGC 用于实现任务规划与飞行状态监控。系统在检测到高风险溺水事件后，根据视觉检测得到的目标位置信息与语义分析结果，生成无人机调度指令，并通过 MAVLink 通信协议发送至飞控系统，驱动无人机执行巡检与目标跟踪任务。
（1）无人机任务调度模型
考虑到开放水域监控场景中可能存在多个无人机协同工作，或同时检测到多起溺水事件的情况，本文提出简单的任务调度策略。在本系统中，无人机部署在监控附近，当检测到高风险溺水事件后，立即触发无人机起飞执行救援任务。对于多无人机或多事件场景，可构建任务调度优先级函数，综合考虑风险等级、距离和电量：
P_{\mathrm{task}}=\omega_1\cdot R+\omega_2\cdot\left(1-\widetilde{D}\right)+\omega_3\cdot\widetilde{S}
其中：
	R为风险等级（取值范围为0到1）
	\widetilde{D}为归一化距离（取值范围为0到1，0表示距离最近）
	\widetilde{S}为归一化电量（取值范围为0到1，1表示电量最充足）
	\omega_1,\omega_2,\omega_3为权重系数，满足\sum_{i=1}^{3}\omega_i=1，且\omega_1>\omega_2>\omega_3（优先考虑风险等级）
在本研究的仿真验证中，仅考虑单无人机单事件的简化场景，当检测到高风险溺水事件（R>R_{\mathrm{th}}）且无人机电量充足（S>S_{\mathrm{min}}，其中 S_{\mathrm{min}} 为最低起飞电量阈值）时，无人机将起飞执行任务。
（2）视觉导航与跟踪算法
考虑到本系统中无人机部署在监控附近，溺水人员与无人机距离较近，因此不需要复杂的远距离路径规划，重点关注目标附近的视觉导航与跟踪任务，预计采用YOLO + 卡尔曼滤波的双模跟踪机制，结合YOLO检测的准确性和卡尔曼滤波的预测能力，实现对溺水人员的持续、稳定跟踪。
为实现对目标的运动状态估计，首先定义包含位置和速度信息的二维运动状态向量：
\mathbit{x}_k=\left[\begin{matrix}x_k&y_k&v_{x,k}&v_{y,k}\\\end{matrix}\right]^T
其中 \left(x_k,y_k\right)表示目标在第 k 帧图像中的像素坐标，\left(v_{x,k},v_{y,k}\right) 表示目标在图像平面 x 和 y 方向的运动速度分量。基于上一帧的状态估计结果，利用运动模型预测当前帧的目标状态。该阶段包括状态预测方程和协方差预测方程：
{\hat{\mathbit{x}}}_{k|k-1}=F{\hat{\mathbit{x}}}_{k-1|k-1}
P_{k|k-1}=FP_{k-1|k-1}F^T+Q
其中：
	F 为状态转移矩阵，描述目标从第 k-1 帧到第 k 帧的运动演化规律
	{\hat{\mathbit{x}}}_{k\mid k-1} 为基于第 k-1 帧观测的第 k 帧状态预测值
	P_{k\mid k-1} 为状态预测的协方差矩阵
	Q 为过程噪声协方差矩阵，用于描述运动模型的不确定性
视觉观测阶段：通过YOLO目标检测器对当前帧图像进行检测，获取目标的观测位置。观测方程为：
z_k=\mathrm{YOLO-detect}\left(I_k\right)
其中 I_k 为第 k 帧输入图像，\mathbit{z}_k=\left[\begin{matrix}z_{x,k}&z_{y,k}\\\end{matrix}\right]^T 为YOLO检测器输出的目标中心像素坐标。
状态融合阶段：将预测的状态信息与当前帧的观测信息进行融合，得到最终的状态估计。该阶段包括卡尔曼增益计算、状态更新和协方差更新三个步骤：
K_k=P_{k|k-1}H^T(HP_{k|k-1}H^T+R)^{-1}
{\hat{\mathbit{x}}}_{k|k}={\hat{\mathbit{x}}}_{k|k-1}+K_k(\mathbit{z}_k-H{\hat{\mathbit{x}}}_{k|k-1})
P_{k|k}=\left(I-K_kH\right)P_{k|k-1}
其中：
	K_k 为卡尔曼增益，用于权衡预测信息和观测信息的可信度
	H 为观测矩阵，用于将状态向量映射到观测空间
	R 为测量噪声协方差矩阵，用于描述YOLO检测器的测量误差
	I 为单位矩阵
	{\hat{\mathbit{x}}}_{k\mid k} 为融合后的第 k 帧状态估计值
	P_{k\mid k} 为融合后的状态协方差矩阵
当YOLO检测置信度高时，卡尔曼增益会赋予观测信息更大权重；当检测置信度低或检测失败时，会更多依赖预测结果，从而实现对目标的持续、稳定跟踪。具体表现为鲁棒性、准确性和实时性：鲁棒性体现在当YOLO检测失败或置信度低时，仍能通过预测维持跟踪；准确性体现在当YOLO检测准确时，能及时修正预测误差；实时性体现在计算量小，不影响系统实时性能。
（3）救生设备投放决策模型
本研究的仿真无人机采用底部摄像头配置，摄像头垂直向下拍摄，由于开放水域救援场景中，风速、水流等信息难以直接通过视觉传感器获取，本文提出基于视觉特征的投放决策算法，仅利用无人机视觉信息和自身姿态传感器数据进行决策。
基于单目视觉和目标检测结果进行投放时机判断。设目标在第 t 帧图像中的检测框为 b_t=(x_t,y_t,w_t,h_t)，其中 xtyt 为检测框中心点坐标，wtht 为检测框的宽和高。
投放决策的置信度评分函数基于三个核心视觉特征构建：
C_{drop}=\omega_1\cdot C_{\mathrm{centerness}}+\omega_2\cdot C_{scale}+\omega_3\cdot C_{stability}
其中：
	C_{\mathrm{centerness}}=1-\sqrt{\left(x_t-0.5)^2+(y_t-0.5)^2\right.} 为目标居中度评分，目标越靠近图像中心评分越高
	C_{\mathrm{scale}}=\exp\funcapply-stsopt)22σs2为目标尺寸评分，其中 s_t=\sqrt{w_th_t} 为检测框几何平均尺寸，s_{\mathrm{opt}} 为预设的最优投放尺寸，\sigma_s 为容差系数
	C_{\mathrm{stability}}=1-\frac{1}{N}\sum_{i=1}^{N}\parallel\mathbit{p}_{t-i+1}-\mathbit{p}_{t-i}\parallel 为目标稳定性评分，基于过去 N 帧目标位置的平滑度计算
	\omega_1,\omega_2,\omega_3 为权重系数，满足 \sum_{i=1}^{3}\omega_i=1，且 \omega_1>\omega_2>\omega_3（优先考虑目标居中）
当满足以下条件时触发投放：
C_{\mathrm{drop}}>C_{\mathrm{th}}\mathrm{\ \ and\ \ }R>R_{\mathrm{th}}\mathrm{\ \ and\ \ }|\phi|<\phi_{\mathrm{max}}\mathrm{\ \ and\ \ }|\psi|<\psi_{\mathrm{max}}
其中：
	C_{\mathrm{th}} 为投放置信度阈值
	R 为系统风险指数
	R_{\mathrm{th}} 为风险阈值
	\phi,\psi 分别为无人机的横滚角和俯仰角
	\phi_{\mathrm{max}},\psi_{\mathrm{max}} 为允许的最大姿态角
3.3测试方案
为验证本文提出的溺水监测方法在开放水域场景中的有效性，实验将在模型训练环境、边缘部署环境以及无人机仿真测试环境三个层面进行验证。
在模型训练方面，深度学习模型训练与微调将在云端 GPU 计算平台上完成。计划使用 AutoDL 平台租用 NVIDIA RTX 3090 GPU 进行模型训练与推理实验，深度学习框架采用 Python 3.10 与 PyTorch 2.x。训练数据主要包括公开人体检测数据集（如 COCO、CrowdHuman）以及采集的真实河道监控视频数据，用于训练人体目标检测模型与河道实例分割模型；同时在第二阶段任务中，将结合视频片段与结构化提示词数据对 3B 参数规模的视觉语言模型（如Qwen2.5 VL等）进行领域微调，以提升模型对溺水行为语义的理解能力。
边缘部署环境方面，系统采用搭载 高通 QCS6490 芯片的广翼智联 FVO1 边缘智能开发板作为边缘计算节点，运行 Aidlux操作系统。在该平台上部署改进的小目标检测模型以及基于光流运动熵的异常行为触发模块，实现对监控视频流的实时处理与初步筛选。当检测到可能存在溺水风险的异常行为时，仅上传关键帧至云端进行语义分析。
仿真测试环境方面，本地主机预计采用 WSL2 + Ubuntu 20.04 + ROS Noetic运行环境，并基于 AirSim 无人机仿真平台构建虚拟水域巡检场景。AirSim 通过 Python API 与 PX4 飞控系统进行通信，实现无人机的起飞控制、路径规划与目标跟踪任务，同时使用QGC 进行任务规划与飞行状态监控。实验所涉及的软件版本与硬件配置将在后续实验阶段根据实际部署环境进行适当调整。
